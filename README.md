# Portfólio de Maria Clara

Projeto de portfólio pessoal feito com HTML, CSS e JavaScript.

## Arquivos
- `index.html` — estrutura e conteúdo da página.
- `style.css` — cores, layout e adaptação para celulares.
- `script.js` — menu responsivo, ano automático e interação do formulário.

## Como abrir no VS Code
1. Extraia o arquivo ZIP para uma pasta.
2. Abra o Visual Studio Code.
3. Clique em **File > Open Folder** e selecione a pasta extraída.
4. Se tiver a extensão **Live Server**, clique com o botão direito em `index.html`.
5. Selecione **Open with Live Server**.

Também é possível abrir o arquivo `index.html` diretamente no navegador.

## Personalização
Edite o `index.html` para colocar seus dados reais, escola, curso, contatos e projetos. As barras de habilidades são ilustrativas.

## Observação sobre o formulário
O formulário demonstra uma interação no navegador e não envia mensagens para um servidor. Para receber mensagens de verdade, será necessário conectar um serviço ou criar um backend.
